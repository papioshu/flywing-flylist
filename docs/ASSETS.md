# Assets — FLYLIST landing page

All artwork is by RichFox, from `Fly Wing ASSets.zip` (supplied by the owner 2026-10-14). This repo keeps only the
assets the landing page uses. The full kit (hero, SQUAD, Flight Ahead, phase badges, nav buttons, wireframe) belongs
to the separate FLY WING website build.

## Archival originals (`assets-src/richfox/`, not served, never edited)

| File | What it is |
|---|---|
| `LandingPage Graphic.png` | 1920×1080 RGBA, red sky with manga clouds and the FLY WING brush wordmark baked in at the centre (about x 655–1260, y 575–705). |
| `Header Text Logo.svg` | FLY WING logo, paths only, fill `#872e2c`, viewBox 0 0 453 107. No scripts, text or external refs. |
| `Home Button Top Left.svg` | Bird/feather mark, one path, fill `#872e2c`, viewBox 0 0 83 96.24. |

| `cursor.svg` | Feather cursor, one path, no fill (from the website kit, `Fly Wing ASSets.zip`). |

## Font coverage

ChasingClouds has 56 glyphs: A–Z, a–z, space, and nothing else, so no digits or punctuation. The owner confirmed it is
a capitals-only display face. It is used only for uppercase display words ("FLYLIST" heading and modal side panel),
always with `text-transform: uppercase`. Text with digits or punctuation, such as "APPLY 4 FLYLIST", uses Oswald.

## Limits of the art

The landing graphic is flattened: clouds and wordmark are one layer, so they can't move independently. Layered exports
from RichFox would be needed for parallax.
